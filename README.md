# Yingya Reader（英雅閱讀器）

簡潔免費的英文閱讀器。

## 主要特點

- 介面簡潔簡約，免費使用且無廣告
- 支援配置 API 接入系統，輔助句段解析與語境理解
- 支援點擊查詞與長按查句，查閱快捷

## 已知限制

- 非原生 Android 軟體封裝，部分機型適配一般，執行時效能與記憶體佔用較大
- 使用過程中偶現 Bug

## 安裝與使用

- 執行需求：Android 8.0 及以上版本，或直接以瀏覽器開啟 `src/` 內前端檔案
- 安裝方式：前往 `release/` 目錄下載 APK 安裝檔直接安裝

## 目錄結構

- `src/`：前端原始碼與靜態資源
- `release/`：已簽章發行的 Android APK 安裝檔
- `android_template/`：Android 殼層與畫面適配範本

## 問題回報

若於使用過程中遇到介面異常或功能錯誤，歡迎於 GitHub Issues 提交說明與裝置型號資訊。
